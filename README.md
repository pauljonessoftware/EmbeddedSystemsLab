# Arduino & Embedded Systems Lab

**Author:** Paul A. Jones, Jr.  
**Focus:** Electronics, Arduino, C Programming, and Embedded Systems

## Overview

This repository documents my hands-on journey into electronics and embedded systems engineering. Through practical experiments, circuit construction, component measurements, and programming exercises, I am rebuilding foundational engineering skills while developing new capabilities.

## Areas of Study

- **Electronics:** Resistors, LEDs, transistors, potentiometers, and circuit analysis.
- **Arduino:** Digital and analog interfaces, libraries, timing, and interrupts.
- **C Programming:** Pointers, arrays, memory management, and data structures.
- **Embedded Systems:** Hardware/software integration, testing, and troubleshooting.

## Field Reports

My field reports document experimental objectives, circuit configurations, measurements, observations, results, and lessons learned. Photographs and supporting source code accompany experiments whenever applicable.

## Philosophy

**Measure it. Build it. Test it. Document it.**

This repository is a record of continuous learning through experimentation, disciplined troubleshooting, and practical application.
